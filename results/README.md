# Released manuscript statistics

- `patterns_unified_statistics.json` contains the aggregate relation-level and patient-level statistics used in the manuscript and Supplement.
- `patterns_patient_statistics.csv` provides a compact patient-level view of the paired Direct-versus-RelScope effects.

The JSON retains `RelMeasure3D` in some field names because it is the development identifier used when the frozen statistics were generated. In the manuscript and repository narrative, the same model is named RelScope.

These files contain derived numerical summaries only. They do not contain medical images, voxel arrays, or checkpoints.
